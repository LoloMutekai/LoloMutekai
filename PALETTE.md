# Ink and dusty rose

The palette links the profile and the A.C.C.E.S.S. public notebook.
Small ribbons and flowers carry the personal style; readable text carries
the technical content.

| Role | Colour |
|---|---|
| Ink | `#0d0e12` |
| Surface | `#16131a` |
| Main text on ink | `#f2e8ed` |
| Supporting text on ink | `#b4acbc` |
| Dusty rose | `#c98ba0` |
| Fine rules | `#2a2730` |

SVG artwork is static, self-contained and includes a title and description.
Essential statements also appear as ordinary Markdown text. The notebook uses
the same visual language without requiring the profile's artwork to load.
